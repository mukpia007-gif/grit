좋은 습관 만들기 (Grit) - 가족용 설치 방법
==========================================

이 앱은 가족이 각자 자기 폰에 설치해서 씁니다.
기록은 각 폰 안에만 저장되므로 서로의 기록이 섞이지 않습니다.
Claude 계정이 없어도 되고, 설치한 뒤에는 인터넷이 없어도 씁니다.


[1] GitHub에 올리기 (PC에서, 처음 한 번만)
------------------------------------------
1. github.com 에 로그인한 뒤 오른쪽 위 + → New repository 를 누릅니다.
2. Repository name 에 grit 이라고 쓰고, Public 을 고른 뒤 Create repository 를 누릅니다.
3. 'uploading an existing file' 을 누릅니다.
4. 이 zip을 푼 폴더 안의 내용물(index.html, manifest.webmanifest, sw.js,
   설치방법.txt, fonts 폴더, icons 폴더)을 전부 선택해서 끌어다 놓습니다.
   ※ 폴더째 올리지 말고, 폴더를 열어 '안의 내용물'을 올려야 합니다.
5. 아래의 초록색 Commit changes 를 누릅니다.
6. 저장소의 Settings → 왼쪽 Pages → Branch 를 None 에서 main 으로 바꾸고 Save 를 누릅니다.
7. 1~2분 뒤 Pages 화면 위쪽에 나오는 주소가 앱 주소입니다.
   예) https://내아이디.github.io/grit/


[2] 가족 폰에 설치하기 (사람마다 각자)
--------------------------------------
1. 앱 주소를 카톡으로 가족에게 보냅니다.
2. 링크를 Chrome 으로 엽니다.
   (카톡 안에서 열리면 ⋮ → '다른 브라우저로 열기' → Chrome)
3. 화면 위쪽의 '설치' 버튼을 누르거나,
   Chrome 오른쪽 위 ⋮ → '앱 설치' 또는 '홈 화면에 추가' → '설치' 를 누릅니다.
4. 홈 화면에 생긴 Grit 아이콘으로 실행합니다.

※ 삼성 인터넷: 아래쪽 ≡ 메뉴 → '현재 페이지 추가' → '홈 화면'


[3] 백업 (각자 가끔씩)
-----------------------
- 앱의 톱니바퀴 → '백업과 복원' → '백업 파일 저장' 을 누르면
  폰의 '다운로드' 폴더에 grit-backup-날짜.json 파일이 저장됩니다.
- 폰을 바꾸면 새 폰에 앱을 설치한 뒤 '백업 불러오기' 로 그 파일을 고르면 기록이 돌아옵니다.
- Chrome의 사이트 데이터를 지우거나 앱을 삭제하면 기록도 지워지니 주의하세요.


[4] 새 버전을 받았을 때
------------------------
- GitHub 저장소에서 Add file → Upload files 로 새 index.html 과 sw.js 를 올리고
  Commit changes 를 누릅니다. 같은 이름의 파일은 새 것으로 바뀝니다.
- 가족 폰의 앱은 다음에 인터넷이 연결된 상태로 열 때 자동으로 새 버전이 됩니다.
  기록은 그대로 남습니다.
